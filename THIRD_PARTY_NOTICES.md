# Third-party components

## LiveKit C++ Client SDK

Community Clash Streamer uses the official LiveKit C++ Client SDK.

- Project: https://github.com/livekit/client-sdk-cpp
- Version used by the release build: 1.11.0
- License: Apache License 2.0

The LiveKit runtime DLLs distributed with release packages are upstream binaries and are not authored by the Community Clash project.

Windows system libraries used by the application are provided by Microsoft as part of Windows and the Windows SDK.
